# 틀 보강 1차 (2026-09-29) — 3단계 판정 · kit-off 비교 · 사용자 방향 반영

## 사용자 방향
실사용자는 요청이 셸에 맞는지 알 수 없다 → **어떤 요청이든 화면은 만든다.** 맞으면 셸을 최대한 따르고, 없으면 우리 문법·토큰으로 일관되게.
시험의 엄격한 규칙(맞는 셸이 없으면 멈춤)은 파이프라인 검증용이었다 — 검증이 끝나 풀었다. 현실 시나리오 시험은 셸·정책을 다시 만든 뒤(설계 13절).
