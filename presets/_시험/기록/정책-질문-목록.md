# 정책 질문 목록 — 셸·정책을 다시 만들기 전에 팀이 정할 것

> 재료: 3단계 시험 화면 9개(kit-on r03 · r13~r20)에서 AI가 남긴 "확인 필요" 60여 개 + 지금 카드 중 제품이 정해야 하는 선택.
> 기준(설계 5-2-1): **AI가 이미 아는 일반 원칙은 카드로 두지 않는다.** 팀이 따로 정해야 화면끼리 같아지는 것만 카드로 둔다.
> "지금 임시값"은 시험용 카드나 AI가 스스로 정한 값이다. **정한 답** 칸을 채우면 그대로 카드가 된다.

## 4. 업무 규칙 — UX 정책이 아니라 요구사항 쪽 질문

이 목록은 정책으로 만들지 않는다. 화면을 요청할 때 요구사항에 적어 줘야 하는 것들이다.
AI가 몰라서 가정한 값의 예: 계약 만료 예정 = 30일 안 · 회의실 운영 09~18시 · 칸 30분 ·
주간 값 = 일간 평균 · 경비 집계 = 결재 완료 · 부가세 포함 · 부분 환불 없음.

> 관찰: AI는 이런 것을 **가정하고 기록**했다. 제품팀용 안내에 "요청할 때 적어 주면 좋은 것" 목록으로 넣으면 좋다.
