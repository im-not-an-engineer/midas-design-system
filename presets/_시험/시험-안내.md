# 3단계 시험 안내 — 직접 돌려 보기

이 시험은 **정답을 모르는 새 세션**이 문장 하나만 받고 화면을 만들게 하는 것입니다.
결과가 셸·정책을 제대로 따르는지는 채점 스크립트가 표로 정리합니다.

## 준비물 (이미 만들어 둠)

| 폴더 | 무엇 |
|---|---|
| `~/Documents/ds-sandbox/kit-on` | 부품 전부 + **에이전트 키트**(셸 20 · 정책 카드 29 · 절차 · 검사 도구) |
| `~/Documents/ds-sandbox/kit-off` | 부품 전부만 — 지금 제품팀이 받는 것과 같다 (비교용) |

처음 상태로 되돌리고 싶으면 터미널에서:

```bash
cd ~/Documents/ds-sandbox && KIT=1 DIR=kit-on ./새로-만들기.sh saas
```

```bash
cd ~/Documents/ds-sandbox && DIR=kit-off ./새로-만들기.sh saas all
```

## 문장 하나를 돌리는 법

1. Claude Code 에서 **새 대화**를 연다. 폴더는 `kit-on` 을 고른다.
2. 권한은 자동 승인으로 두는 편이 편하다 (중간에 멈추지 않게).
3. 아래 문장 중 하나를 **그대로** 붙여 넣는다. 앞의 `[r03]` 도 함께 넣는다 — 화면 이름이 된다.
4. 끝날 때까지 기다린다. 다른 말은 덧붙이지 않는다(힌트가 된다).
5. 다음 문장은 **다시 새 대화**에서. 한 대화에 문장 두 개를 넣지 않는다.

키트 끔(`kit-off`)에서 돌릴 때는 문장 끝에 이 한 줄만 붙인다 (`{id}` 자리에 `r03` 같은 번호). 화면을 찾기 위한 자리 안내일 뿐 힌트는 아니다.

```
화면은 src/pages/{id}.tsx 에 만들고, 주소 #/{id} 로 볼 수 있게 App.tsx 에 연결해줘.
```

## 결과 보기

```bash
cd ~/Documents/ds-sandbox/kit-on && npm run dev
```

브라우저에서 `http://localhost:5173/#/r03` 처럼 문장 번호로 연다. 왼쪽 메뉴에 만든 화면이 모두 보인다.

## 채점

저장소 폴더에서:

```bash
node presets/_시험/채점.mjs ~/Documents/ds-sandbox/kit-on
```

`presets/_시험/기록/3단계/kit-on.md` 에 표가 생긴다. 표 읽는 법:

| 칸 | 뜻 |
|---|---|
| 셸 (고름 → 판정) | 고른 셸과 판정. 정답 · 허용(경계 문장에서 함께 인정) · 오답 · 정답(멈춤: 맞는 셸이 없어서 만들지 않음) |
| 핵심 유형 | 문장에 심어 둔 조건 때문에 **반드시** 골라야 하는 정책. `놓침:` 이 있으면 조건을 못 읽은 것 |
| 금지 유형 | 고르면 틀린 정책 (예: 되살릴 수 있다고 했는데 확인창 삭제) |
| 정적 | 명세 · 슬롯 · 계약 린트 · 타입 검사 |
| 시나리오 | **정답 유형**의 보장이 실제 화면에서 지켜진 개수 |
| 확인 필요 | 에이전트가 스스로 망설였다고 남긴 수 (경계 문장에서는 있어야 좋다) |
| 연 키트 파일 | 세션이 연 셸 · 카드 파일 수 — 전부 열었으면 "고른" 게 아니라 "다 읽은" 것 |

## 몇 번 돌리나

| 조건 | 폴더 | 횟수 |
|---|---|---|
| 키트 켬 | `kit-on` | 문장 15개 × 1 |
| 키트 켬 (흔들림 보기) | `kit-on-2` — `KIT=1 DIR=kit-on-2 ./새로-만들기.sh saas` 로 만든다 | 15개 × 1 |
| 키트 끔 | `kit-off` | 15개 × 1 (채점표 대신 눈으로 비교) |

다 하지 않아도 된다. **명확 몇 개 + 경계 3개 + 없음 2개**만 먼저 돌려도 판정의 방향은 보인다.
끝나면 "채점 결과 봐줘"라고 하면 설계 10절 기준(내용 결함 / 구조 결함)으로 분류한다.

## 눈으로 볼 것

- 셸의 뼈대가 그대로인가 — 셸을 흉내 내어 새로 짰는지는 정적 검사가 잡지만, **내용이 요구에 맞게 채워졌는지**는 눈으로 본다
- 빈 화면 · 에러 · 로딩: 주소에 `?state=empty` 를 붙이면 그 상태로 보인다 (`http://localhost:5173/?state=empty#/r03`)
- 키트 끔과 나란히 놓고, 같은 문장에서 무엇이 달라졌는지
