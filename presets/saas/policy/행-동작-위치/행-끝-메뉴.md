# 행마다 동작이 여럿일 때

**규칙** 행 끝에 **더보기(⋯) 메뉴 버튼 하나**만 두고, 동작은 메뉴 안에 모은다. 파괴적 동작은 메뉴 맨 아래 `destructive`.

**금지** 행마다 [편집][복제][삭제] 버튼을 나란히 두기.

**이유** 버튼이 행마다 반복되면 표가 버튼 격자가 되고, 파괴적 버튼이 잘못 눌리기 쉽다.

```tsx
<Menu><MenuTrigger render={<Button intent="ghost" size="sm" iconOnly aria-label="더보기" />}><Ellipsis aria-hidden /></MenuTrigger>
  <MenuContent align="end"><MenuItem>편집</MenuItem><MenuItem destructive>삭제</MenuItem></MenuContent></Menu>
// 경로: "행버튼": { "역할": "button", "안": { "역할": "row", "순번": 1 } }  (체크칸은 버튼이 아니다)
```
