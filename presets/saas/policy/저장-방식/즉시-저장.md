# 하나씩 바꾸면 곧바로 반영돼도 될 때

**규칙** 스위치·고르기를 바꾸는 즉시 저장하고 토스트로 알린다("메일 알림을 켰습니다"). 실패하면 원래 값으로 되돌리고 화면 안에 알린다.

**금지** 설정 화면 맨 아래 [저장] 버튼. 스위치를 켰는데 저장은 따로 눌러야 하는 것.

**이유** 스위치는 누른 순간 켜졌다고 믿게 만든다. 저장 버튼을 따로 두면 그 믿음이 거짓이 된다.

```tsx
<Switch label="메일 알림" checked={on} onCheckedChange={(v) => { setOn(v); toast.add({ title: `메일 알림을 ${v ? '켰' : '껐'}습니다` }); }} />
```
