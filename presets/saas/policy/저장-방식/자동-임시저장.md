# 오래 쓰는 글을 잃지 않게 할 때

**규칙** 입력을 멈추고 1~2초 뒤 **임시 저장**하고, 제목 줄 옆에 "임시 저장됨 · 14:32"를 적는다. 다시 열면 이어 쓴다. 게시·제출은 따로 버튼으로 한다.

**금지** 창을 닫으면 다 사라지는 긴 글 입력. 임시 저장을 했는지 알 수 없게 두기.

**이유** 긴 글을 잃는 것은 되돌릴 수 없는 손실이다. 저장됐다는 표시가 있어야 안심하고 쓴다.

```tsx
useEffect(() => { const t = setTimeout(() => { localStorage.setItem(KEY, body); setSavedAt(now()); }, 1200); return () => clearTimeout(t); }, [body]);
<span role="status" className="text-caption text-fg-muted">임시 저장됨 · {savedAt}</span>
```
