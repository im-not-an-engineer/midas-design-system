# 여러 칸을 채운 뒤 한 번에 저장할 때

**규칙** 바닥 줄에 **[취소] [저장]**(저장이 primary). 바뀐 것이 없으면 저장을 비활성으로 두고 옆에 "바뀐 내용이 없습니다"를 적는다. 저장 중에는 버튼 안 로딩.

**금지** 칸을 떠날 때마다 몰래 저장하기(사용자는 아직 확정하지 않았다). 저장 버튼을 폼 맨 위에만 두기.

**이유** 여러 칸은 한 덩어리로 맞아야 뜻이 있다. 확정 시점을 사용자가 정한다.

```tsx
<Button intent="secondary" onClick={cancel}>취소</Button>
<Button intent="primary" loading={saving} disabled={!dirty} onClick={save}>저장</Button>
```
