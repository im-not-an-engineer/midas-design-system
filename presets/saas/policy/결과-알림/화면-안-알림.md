# 동작이 실패해서 사용자가 고쳐야 할 때

**규칙** 화면 안, 문제가 난 자리 위에 `Alert status="danger"` 로 남긴다. 무엇이 실패했는지,
무엇을 하면 되는지 적고 **다시 시도** 같은 동작을 `action` 에 둔다.

**금지** 실패를 토스트로만 알리기(몇 초 뒤 사라져서 이유를 다시 볼 수 없다).

**이유** 실패는 사용자가 행동해야 끝나는 일이다. 사라지는 알림으로는 그 행동을 이끌 수 없다.

**검사하려면** 실패할 수 있는 동작을 `useShellFail()` 로 감싸고 명세의 `실패 흉내` 에 적는다.
경로: `"실패동작": "deactivate"`(주소 `?fail=` 에 붙는 이름), `"알림": { "역할": "alert" }`, `"다시시도": { "역할": "button", "이름": "다시 시도", "안": "알림" }`.

```tsx
<Alert status="danger" title="목록을 불러오지 못했습니다"
  action={<Button size="sm" onClick={retry}>다시 시도</Button>}>
  네트워크 연결을 확인한 뒤 다시 시도하세요.
</Alert>
```
