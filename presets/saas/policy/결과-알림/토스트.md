# 동작이 성공했음을 알릴 때

**규칙** 토스트로 알린다. 제목은 **무엇이 어떻게 됐는지**("3개 계정을 비활성화했습니다").
사용자의 흐름을 막지 않는다.

**금지** 성공을 대화상자로 알리기(닫기를 한 번 더 누르게 된다). "성공했습니다"처럼 대상이 빠진 문구.

**이유** 성공은 확인만 하면 되는 소식이다. 흐름을 멈출 이유가 없다.

```tsx
const toast = useToastManager();
toast.add({ title: `${n}개 계정을 비활성화했습니다`, type: 'success' });
```
