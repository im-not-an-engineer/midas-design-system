# 많은 행을 쪽으로 나눠 보일 때

**규칙** 표 아래에 쪽 번호와 [이전]·[다음]을 두고, 전체 건수와 지금 범위("41–60 / 1,240")를 적는다. 한 쪽 크기는 고를 수 있게 해도 된다.

**금지** 끝없이 이어 붙이기(위치를 다시 찾을 수 없다). 전체 건수를 숨기기.

**이유** 업무 목록은 "아까 3쪽에 있던 것"을 다시 찾는 일이 잦다. 쪽 번호가 위치를 기억하게 한다.

```tsx
<nav aria-label="쪽" className="flex items-center gap-inline-sm">
  <Button size="sm" intent="ghost" disabled={page === 1} onClick={prev}>이전</Button>
  <span className="text-caption text-fg-muted">{from}–{to} / {total}</span>
  <Button size="sm" intent="ghost" disabled={page === last} onClick={next}>다음</Button>
</nav>
// 경로: "한쪽개수": "20" (대상이 표의 행이면 머리 줄 1 을 더한다)
```
