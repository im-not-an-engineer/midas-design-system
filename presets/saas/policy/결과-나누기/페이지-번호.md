# 많은 행을 쪽으로 나눠 보일 때

**규칙** 표 아래 바닥 줄에 `Pagination` 을 두고, 왼쪽에 전체 건수와 지금 범위("41–60 / 1,240")를 적는다. 쪽 이동 버튼을 손으로 짜지 않는다 — 화면마다 모양이 갈린다.

**금지** 끝없이 이어 붙이기(위치를 다시 찾을 수 없다). 전체 건수를 숨기기.

**이유** 업무 목록은 "아까 3쪽에 있던 것"을 다시 찾는 일이 잦다. 쪽 번호가 위치를 기억하게 한다.

```tsx
<span className="text-caption text-fg-muted">{from}–{to} / {total}</span>
<Pagination page={page} pageCount={pages} onPageChange={setPage} />
// 경로: "다음쪽": { "역할": "button", "이름": "다음 쪽" } · "한쪽개수": "11" (대상이 표의 행이면 머리 행 1 을 더한다)
```
