# 되돌릴 수 있는 것을 지울 때

**규칙** 묻지 않고 바로 지운다. 대신 결과 알림에 **되돌리기**를 붙인다. 되돌리면 원래 자리로 돌아온다.
알림 문구에 어디로 갔는지(휴지통 등)와 언제까지 복구되는지 적는다.

**금지** 확인 대화상자. 되돌릴 수 있는데 매번 묻는 것은 사용자를 두 번 일하게 한다.

**이유** 확인창은 되돌릴 수 없을 때만 값을 한다. 되돌릴 수 있으면 실수는 되돌리기로 푸는 편이 빠르다.

```tsx
const toast = useToastManager();
function remove(item) {
  setItems((xs) => xs.filter((x) => x.id !== item.id));
  toast.add({
    title: `‘${item.name}’을 휴지통으로 옮겼습니다`,
    description: '30일 동안 복구할 수 있습니다.',
    actionProps: { children: '되돌리기', onClick: () => restore(item) },
  });
}
```
