# 삭제 — 결정표

요구사항에서 **사실로 확인되는 조건**으로 유형을 하나 고른다. 위에서부터 맞는 첫 줄.

| 조건 | 유형 |
|---|---|
| 되돌릴 수 있다 — 휴지통, 복구 기간, 보관함이 있다 | 즉시-되돌리기 |
| 되돌릴 수 없고, 딸린 데이터까지 함께 지워진다 | 강한-확인 |
| 되돌릴 수 없고, 영향이 그 항목에 그친다 | 확인 |
| 요구사항에 정보가 없다 | 확인 |

- 정보가 없어서 기본값(확인)을 썼으면 명세의 `확인 필요` 에 적는다.
- 여러 건을 한꺼번에 지울 때도 같은 표로 고르고, 확인 문구에 **개수**를 적는다.
- 경로의 `지울것` 은 **지울 그 항목**을 목록 안에서 이름으로 가리킨다 — 예: `{ "역할": "row", "이름": "강민준", "안": { "역할": "table", "이름": "직원 계정" } }`.
  행 수를 세지 않는 이유: 쪽으로 나뉜 목록에서는 하나를 지우면 다음 것이 올라와 수가 그대로다.
