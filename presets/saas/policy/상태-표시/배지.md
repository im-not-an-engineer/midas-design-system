# 이름으로 나뉘는 상태를 보일 때

**규칙** `Badge` 에 상태의 **뜻**으로 `status` 를 고른다. 색을 직접 칠하지 않는다. 같은 화면에서 variant 를 하나로 둔다(기본 subtle).

**금지** 글자 색만 바꾸기. 상태마다 색을 취향으로 고르기(주황 = 대기 같은 것).

**이유** 색이 뜻에 묶여 있어야 화면마다 같은 색이 같은 뜻이 된다.

```tsx
<Badge status={STATUS[c.state]}>{LABEL[c.state]}</Badge>
```
