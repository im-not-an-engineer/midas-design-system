# 상태가 비율일 때

**규칙** `Meter` 로 막대를 그리고 옆에 숫자(%)를 함께 적는다. 목표를 넘기면 넘긴 값을 그대로 적는다(125%).

**금지** 비율을 배지 한 칸으로 줄이기. 숫자 없이 막대만.

**이유** 비율은 길이로 먼저 읽고 숫자로 확인한다. 둘 중 하나가 빠지면 읽는 데 두 번 걸린다.

```tsx
<Meter label="목표 진행" value={75} showValue />
// 경로: "막대": { "역할": "meter" }, "비율글자": { "역할": "meter" }
```
