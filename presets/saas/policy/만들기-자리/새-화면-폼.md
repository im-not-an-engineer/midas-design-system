# 칸이 많은 것을 새로 만들 때

**규칙** 만들기를 누르면 전체 페이지 폼(form 셸)으로 간다. 폼 위에 목록으로 돌아가는 길, 바닥에 [취소][저장].

**금지** 칸 열 개를 대화상자에 욱여넣기(스크롤이 생기고 바닥 버튼이 가린다).

**이유** 긴 입력은 온전한 화면과 떠나기 보호가 필요하다.

```tsx
<Button intent="primary" onClick={() => go('new')}>새 계약 등록</Button>
```
