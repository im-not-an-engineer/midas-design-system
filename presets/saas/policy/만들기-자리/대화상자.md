# 칸이 적은 것을 새로 만들 때

**규칙** `Dialog` 에 칸을 넣고 바닥은 `DialogConfirmFooter`(확인 문구는 동작 이름: "만들기" · "초대"). 저장하면 닫고 목록 맨 위에 보이며 결과를 알린다.

**금지** 칸 두세 개를 위해 화면을 바꾸기. 저장 뒤 목록을 새로 고쳐야 보이게 두기.

**이유** 짧은 입력은 목록 위에서 끝내는 편이 빠르고, 만든 것이 곧바로 보여야 됐다고 믿는다.

```tsx
<Dialog open={open} onOpenChange={setOpen}><DialogContent><DialogHeader><DialogTitle>계정 초대</DialogTitle></DialogHeader>…<DialogConfirmFooter confirmLabel="초대" onConfirm={create} /></DialogContent></Dialog>
```
