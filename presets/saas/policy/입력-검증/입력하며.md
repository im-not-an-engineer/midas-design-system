# 규칙을 맞춰 가며 입력해야 할 때

**규칙** 규칙(8자 이상 · 숫자 포함 …)을 칸 아래에 **처음부터** 적어 두고, 입력하는 동안 규칙마다 맞았는지 바로 바꿔 보인다.

**금지** 규칙을 숨겨 두었다가 저장할 때 한꺼번에 알리기.

**이유** 맞춰 가며 쓰는 칸은 틀렸다는 말보다 무엇이 남았는지가 필요하다.

```tsx
<FieldDescription>{rules.map((r) => <span key={r.id}>{r.ok(v) ? '✓' : '·'} {r.label}</span>)}</FieldDescription>
```
