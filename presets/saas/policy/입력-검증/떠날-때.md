# 형식이 있는 칸의 오류를 알릴 때

**규칙** 칸을 **떠날 때** 검사해서 `Field invalid` + `FieldError` 로 칸 바로 아래에 적는다. 무엇이 틀렸고 어떻게 고치는지 쓴다. 저장을 눌렀을 때 한 번 더 모두 검사한다.

**금지** 한 글자 칠 때마다 빨간 오류 띄우기(아직 다 쓰지도 않았다). 오류를 폼 맨 위에만 모아 두기.

**이유** 쓰는 중에 틀렸다고 하면 방해가 되고, 떠날 때 알리면 바로 고칠 수 있다.

```tsx
<Field invalid={touched && !valid}>
  <FieldLabel>이메일</FieldLabel>
  <Input value={v} onChange={(e) => setV(e.target.value)} onBlur={() => setTouched(true)} />
  <FieldError match={touched && !valid}>이메일 형식이 아닙니다 — 예: name@corp.kr</FieldError>
</Field>
// 경로: "오류": { "글자": "이메일 형식이 아닙니다" }, "틀린값": "abc", "맞는값": "a@corp.kr"
```
