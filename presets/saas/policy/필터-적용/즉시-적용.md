# 조건을 바꾸면 결과가 곧바로 바뀌어도 될 때

**규칙** 검색칸·고르기를 바꾸는 즉시 결과를 다시 보인다. 검색칸은 글자를 멈춘 뒤 반영해도 된다. 조건 줄 끝에 **초기화**를 둔다.

**금지** 가벼운 목록에 [검색]·[적용] 버튼을 따로 두기. 초기화 없이 조건을 여럿 두기.

**경로를 적을 때** `조건바꾸기` 에는 목데이터에서 **결과 수가 실제로 달라지는** 조건을 고른다 — 바꿔도 수가 같으면 검사가 결과를 알아볼 수 없다.

**이유** 누를 필요가 없는 버튼은 한 번 더 일하게 한다. 조건이 여럿이면 처음으로 돌아갈 길이 있어야 한다.

```tsx
<Select items={DEPTS} value={dept} onValueChange={(v) => setDept(v ?? 'all')} />
<Button intent="ghost" onClick={reset}>초기화</Button>
// 경로: "조건바꾸기": [{ "역할": "combobox", "이름": "부서" }, { "역할": "option", "이름": "개발" }]  또는  [{ "역할": "textbox", "이름": "이름 검색", "입력": "김" }]
```
