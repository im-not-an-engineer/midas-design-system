# 여러 항목을 골라 한꺼번에 처리할 때

**규칙** 항목마다 고르기 칸을 두고, **하나라도 고르면** 목록 위에 일괄 작업 줄이 나타난다.
줄에는 고른 개수와 동작 버튼, 선택 해제를 둔다. 머리 칸의 고르기는 보이는 항목 전체를 고른다.

**금지** 일괄 동작 버튼을 늘 보이게 두고 비활성으로 막기. 고른 개수를 보여주지 않기.

**이유** 고르기 전에는 쓸 수 없는 버튼이 자리를 차지하면 화면이 시끄럽다. 개수가 보여야
사용자가 몇 개에 동작하는지 알고 누른다.

```tsx
{selected.size > 0 && (
  <div role="toolbar" aria-label="일괄 작업" className="…">
    <span>{selected.size}개 선택됨</span>
    <Button size="sm" onClick={deactivate}>비활성화</Button>
    <Button size="sm" intent="ghost" onClick={clear}>선택 해제</Button>
  </div>
)}
```
