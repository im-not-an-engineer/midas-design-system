# 목록을 오가며 한 건씩 옆에서 볼 때

**규칙** 고른 항목을 목록에서 표시하고(선택 면), 옆 칸에 상세를 연다. 목록은 움직이지 않는다.

**금지** 옆 칸이 있는데 새 화면으로 넘기기.

**이유** 여러 건을 차례로 볼 때 화면이 바뀌면 흐름이 끊긴다.

```tsx
<TableRow interactive selected={row.id === selectedId} onClick={() => setSelectedId(row.id)}>…</TableRow>
```
