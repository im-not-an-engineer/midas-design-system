# 한 건을 따로 오래 볼 때

**규칙** 항목(행 전체 또는 이름)을 누르면 상세 화면으로 바뀐다. 상세 위에 **목록으로** 돌아가는 길을 둔다. 돌아오면 필터·쪽이 그대로다.

**금지** 돌아왔는데 필터와 쪽이 초기화되기.

**이유** 길게 볼 내용은 온전한 화면이 필요하고, 돌아왔을 때 찾던 자리가 남아 있어야 한다.

```tsx
<TableRow interactive onClick={() => open(row.id)}>…</TableRow>
<Button intent="ghost" size="sm" onClick={back}>‹ 목록으로</Button>
```
