# 목록을 떠나지 않고 잠깐 볼 때

**규칙** 오른쪽 `Drawer` 로 연다. 제목에 항목 이름, 닫기 단추, 필요하면 바닥에 동작 한두 개.

**금지** 서랍 안에 탭·긴 폼을 넣기(그건 새 화면이다).

**이유** 잠깐 볼 것 때문에 목록을 떠나면 돌아오는 비용이 더 크다.

```tsx
<Drawer open={open} onOpenChange={setOpen}><DrawerContent><DrawerHeader action={<DrawerCloseButton />}><DrawerTitle>{item.name}</DrawerTitle></DrawerHeader>…</DrawerContent></Drawer>
```
